## 🎯 Objectives

The main objectives of this lab work are:

- Understand Java program structure and syntax
- Work with variables, data types, and operators
- Use conditional statements and loops effectively
- Write modular programs using functions/methods
- Learn *Object-Oriented Programming (OOP)* concepts including:
  - Classes and Objects
  - Constructors
  - Methods
  - Encapsulation and Data Hiding
